# 📱 小屏设备操作

目前，CoCo Next 正在针对小屏设备进行布局优化，在这期间，小屏布局还并不完善，可能出现较多问题。

## 全屏

可以通过 **侧栏全屏按钮** 或 **头部菜单栏 》设置 》显示 》全屏** 按钮来进入全屏模式。

## 异常情况处理

遇到问题时，可以给我们[反馈](../feedback)，同时参考下面的方法暂时缓解所遇到的问题。

### 布局未更新

尝试调整显示大小（旋转屏幕、退出全屏等）以触发布局更新。

### 部分内容未适配

通过 **头部菜单栏 》设置 》显示 》缩小显示** 按钮来缩小显示。
