# 插件实现简介

## 一、基本概念

### 1. 入口

在 CoCo Next 中，当插件被激活，会执行入口文件。入口文件是一段 JS 脚本。CoCo Next 会脚本提供功能注册函数，脚本需要在顶层中调用这些功能注册函数来扩展 CoCo Next 的功能。

### 2. 资源

插件并不只有入口文件。在 CoCo Next 中，插件以文件夹的形式存在，该文件夹需要存放插件的所有资源。

插件的资源通常会包括：

- `README.md`：自述文件，用于较为详细的介绍插件。
- `package.json`：NPM 包文件，包含插件的基本信息，如：ID、名称、作者、版本。
- `index.js`：插件入口文件，当插件被激活时，该文件会被执行。

### 3. 功能注册函数

在入口文件中，CoCo Next 会通过模块给脚本提供功能注册函数以让脚本扩展相应功能。

需要注意的是：

1. 功能注册函数必须在入口脚本的顶层被调用，即不能在函数、条件/循环分支等内部调用功能注册函数，这么做可能会导致 CoCo Next 无法识别到相应功能，导致懒加载异常。
2. 每个功能注册函数至多只能调用一次，如果重复调用，只有最后一次调用的结果会生效。

## 二、特性

### 1. 权限管理

目前，插件代码通过沙箱进行隔离，并限制了所有对浏览器 API 的访问。将来会添加权限管理功能，将浏览器 API 有限制地提供给插件。

### 2. 懒加载

插件只有在激活的时候才会被加载，而不是随编辑器一起启动，这样可以防止插件拖慢编辑器的启动速度。

要实现懒加载，必须知道插件注册了那些功能，这样才能实现调用相关功能时自动加载插件。CoCo Next 在安装插件时，会执行一遍入口文件，在这期间，入口文件需要调用功能注册函数，CoCo Next 会记录这些对功能注册函数的调用，以知晓插件所注册的功能。此后，插件仅会在相应功能被使用时启动。
