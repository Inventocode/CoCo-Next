# 派生

尽管还原 CoCo 源代码是一个漫长的过程，但是 CoCo 源代码计划允许已还原和未还原的代码混合运行，使得 CoCo 源代码计划现在就可以被用来派生 CoCo。

你可以使用 CoCo 源代码计划还原出来的代码制作其他功能，如：制作绕审核 Player。要基于 CoCo 源代码计划派生 CoCo，建议以 CoCo 源代码计划的 `pure` 分支基础，该分支不包含用于还原 CoCo 代码的辅助文件。

:::warning
不建议更改未还原的代码（位于 /unrestored 中的代码），这些代码由脚本自动生成，难以阅读并且可能经常出现较大变更！
:::
